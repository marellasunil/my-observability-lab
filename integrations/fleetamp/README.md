# FleetAMP optional lab

These are reference manifests from the FleetAMP development lab, not a portable released image. Build the matching FleetAMP and supervisor images from https://github.com/marellasunil/FleetAMP and import into each eligible node runtime or use a registry and adjust image references/pull policies. Replace local-path with your storage class. Create fleetamp-lab-secrets with random opamp-token and server-pepper values privately before applying. See upstream FleetAMP documentation for bootstrap and token handling. Do not commit credentials. Apply the server manifest first, wait for readiness, then the test collector. The test collector starts with remote configuration acceptance disabled. Use loopback port-forward to service/fleetamp-lab 18080:8080. Plaintext OpAMP is lab-only; use TLS for real deployments. Image availability, storage permissions and remote configuration testing remain required.
